# Golpe ou não?

Landing page educativa sobre golpes digitais, feita como atividade de extensão do curso de Análise e Desenvolvimento de Sistemas da FASIPE Cuiabá, dentro do tema Direito e Cidadania.

Desenvolvido para a comunidade.

## Conteúdo

- Teste interativo com cinco mensagens para identificar o que é golpe e o que é seguro
- Os golpes mais comuns e o que fazer em cada caso
- Sinais de alerta
- Passo a passo para quem caiu em um golpe
- Direitos do cidadão diante de fraudes digitais

## Acessibilidade

- Fonte Atkinson Hyperlegible, pensada para leitura fácil
- Navegação completa por teclado, com link para pular ao conteúdo
- Respostas do teste anunciadas para leitores de tela
- Animações desligadas para quem ativa a opção de reduzir movimento no sistema
- Layout adaptado para celular, tablet e computador

## Tecnologias

HTML, CSS e JavaScript, sem frameworks e sem etapa de build. As fontes são carregadas pelo Google Fonts.

## Estrutura

```
index.html        página principal
css/style.css     estilos, componentes e animações
js/quiz.js        lógica do teste interativo e do botão de compartilhar
img/favicon.svg   ícone do site
```

## Como executar

Abra o arquivo `index.html` no navegador. Não é preciso instalar nada.

## Publicação

O site é publicado com o GitHub Pages a partir da branch `main`.

## Aviso

Conteúdo educativo. Não substitui orientação jurídica.
